## TomTom key default persistence reduced — 14 November 2026

- [Public Pages PR #7](https://github.com/Zux12/jalan-navigation/pull/7) changed `tomtom-live.js`: TomTom key entered with **Remember unchecked** now remains only in the current page's password input memory, not in `sessionStorage` or `localStorage`. On initialization, legacy `sessionStorage` TomTom key is cleared. Only an explicitly checked **Remember** action writes to `localStorage`. Unchecking the box immediately removes that stored value, while the currently open input may still be used until page close or “Forget key”; “Forget key” still clears saved values and invalidates routes/requests. This is intentionally a privacy-first behavior change: an unremembered key is no longer restored after page reload.
- Added targeted local VM unit tests and an assertion in the actual 390px Chromium test that neither storage area holds an unremembered key after a successful mocked route.
